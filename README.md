# Canvas Game

A simple interactive canvas-based game built with React featuring an animated car.

## Getting Started

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to play.

## How to Play

- **Arrow Up**: Increase car speed
- **Arrow Down**: Decrease car speed
- The car automatically bounces off screen edges

## Features

- Canvas-based 2D rendering
- Real-time animation with requestAnimationFrame
- Keyboard controls
- Responsive to window size

## Build

```bash
npm run build
```
